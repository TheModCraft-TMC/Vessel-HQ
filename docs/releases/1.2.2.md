# Vessel HQ 1.2.2

Vessel HQ 1.2.2 is a production hotfix for Cloudflare-proxied Next.js pages.

## Fixed

- Adds `Cache-Control: no-transform` to dynamic frontend responses so CDN and
  security middleware do not inject markup into the streamed React Server
  Component document.
- Prevents Cloudflare client-side verification injection from closing the
  initial React stream with error 412 and leaving a blank page.
- Retains the per-request CSP nonce and OAuth callback fixes shipped in 1.2.1.

- `themodcrafttmc/portainer:1.2.2`
