# Vessel HQ 2.39.3.2.27-beta.4

This beta fixes log viewer selection and authentication error feedback after
`2.39.3.2.27-beta.3`. API and database compatibility remain at Portainer `2.45.0`.

## Changes

- Restores selected-line highlighting in container, service, and task logs.
  CSS class names were joined without spaces, so selecting a line updated the
  selection state without displaying its highlight.
- Restores log line wrapping, scrolling, and the log viewer's styles when
  wrapping is enabled.
- Displays the server's authentication error message instead of the generic
  Axios "Request failed with status code 422" message.
- Release tags no longer automatically trigger CI image publication. This
  release is built, tested, and pushed locally.

## Login by IP address

Internal login uses the account's saved username and local password. An email
address works when it is the saved username; it is not a separate login alias.
When OAuth is enabled, password login remains available only to the initial
admin. Other OAuth accounts must use their identity provider.

Email-as-username login over an IP address was verified in an isolated beta
container. An unrelated email correctly returns "Invalid credentials".

## Publication and verification

Publish the immutable Docker tag `themodcrafttmc/portainer:2.39.3.2.27-beta.4`
and the `themodcrafttmc/portainer:beta` alias at the same OCI index digest, for
Linux AMD64 and ARM64. Keep stable `latest` unchanged.

Final validation results, image digest, and checksummed Linux downloads are
recorded on the GitHub prerelease. Deployment and rollback are documented in
the [release guide](../themodcraft/release-and-deployment.md).
