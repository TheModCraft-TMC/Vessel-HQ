# Vessel HQ 1.3.3-beta.1

Experimental issue #299 candidate. It preserves the Portainer 2.45.0 API/datastore
compatibility identity and uses the standalone extension SDK beta.2.

- Package-declared extension settings schemas and package-bound mTLS runtime
  reads, with independent approval for secret delivery.
- Shared Docker engine event streams for viewed environments, coalesced query
  invalidation, bounded clients and authentication/authorization rechecks.
- Optional signed, local-only webhook fan-out with route-bound signatures,
  bounded concurrency, durable replay reservations and value-free audits.
- Strict activity filters and spreadsheet-safe CSV export.
- Seven reviewed upstream security/compatibility backports for Compose, Git,
  Helm, Kubernetes deletion/TLS and Docker volume ownership.
- Existing source-backed Git reference and file selectors available without
  an edition check; manual paths, HEAD and explicit commit refs are preserved.
- Experimental opt-in shared-storage active/standby startup, with Kubernetes
  and Docker/VM examples. Cross-host coherent locking and storage fencing are
  prerequisites; this is not active/active or database replication.

The [issue acceptance matrix](../planning/issue-299.md) records source tests and
remaining live-provider, production activation and cross-host failover coverage.
This candidate does not establish full Business Edition parity or close #299.
Stable `latest` is not promoted by a prerelease. Existing published tags are
immutable. Production runtime replacement is a separate operation.
