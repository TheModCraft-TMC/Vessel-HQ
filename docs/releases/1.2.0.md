# Vessel HQ 1.2.0

Vessel HQ 1.2.0 is the first official stable Vessel HQ release. API and
database compatibility remain at Portainer `2.45.0`.

## Highlights

- Moves the complete console route surface to the Next.js App Router: 161
  application-owned pages and five intentional redirects, with no partial or
  noncompliant routes in the migration index.
- Reduces the initial client JavaScript from the previous 7.71 MiB entrypoint
  to approximately 1.49 MiB raw (0.43 MiB gzip) in the production build.
- Moves route implementations beside their App Router pages and removes the
  transitional console-page bridge layer.
- Improves responsive navigation, page headers, environment views, Docker and
  Kubernetes resource screens, and loading behavior.
- Continues domain-boundary cleanup, including Environment-owned platform,
  route, and environment classification utilities.
- Hardens GitOps secret renewal, proxy request handling, authentication,
  remote deployment, live logs, and generated API integration.

## Compatibility and updates

- The Vessel HQ product and image version is `1.2.0`.
- The upstream API and datastore schema version remains `2.45.0`.
- Update discovery separates three-part Vessel HQ versions from historical
  five-part fork tags in the existing Docker Hub repository.

## Images

The release publishes the same multi-architecture OCI image under:

- `themodcrafttmc/portainer:1.2.0`
- `themodcrafttmc/portainer:latest`

Both references support Linux AMD64 and ARM64 and must resolve to the same OCI
index digest. The verified digest and checksummed Linux binaries are recorded
on the GitHub release.
