# Vessel HQ 1.2.3

Vessel HQ 1.2.3 improves navigation continuity and loading-state stability.

## Improved

- Internal sidebar navigation now uses the Next.js client router, keeping the
  main Vessel HQ shell mounted while switching between areas such as Templates
  and Stacks.
- Console route transitions render a structured page placeholder inside the
  existing shell instead of flashing an empty canvas.
- Loading data tables reserve a stable, responsive content height and show an
  accessible centered spinner, preventing layout jumps when rows arrive.
