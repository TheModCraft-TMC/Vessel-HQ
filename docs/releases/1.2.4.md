# Vessel HQ 1.2.4

Vessel HQ 1.2.4 fixes stale authentication recovery on the public hostname.

## Fixed

- `/login` no longer assumes that the mere presence of an authentication cookie
  represents a valid session.
- Expired, revoked, or otherwise invalid cookies can now reach the login page,
  where normal session restoration clears the stale state and presents OAuth or
  internal authentication.
- Prevents the public-domain redirect loop between the protected application,
  logout, and login pages that appeared as a blank screen.
