# Vessel HQ 1.2.1

Vessel HQ 1.2.1 is a production hotfix for the Next.js frontend introduced in
1.2.0. API and database compatibility remain at Portainer `2.45.0`.

## Fixes

- Restores frontend hydration under Content Security Policy by generating a
  unique script nonce for every HTML response and applying it to Next.js
  scripts without enabling `unsafe-inline`.
- Restores the OAuth/SSO login button after the public settings request loads.
- Preserves OAuth callback `code`, `state`, and provider error parameters when
  unauthenticated callbacks are redirected from `/` to `/login`.
- Prevents the Go frontend proxy from replacing the nonce-aware policy emitted
  by Next.js while retaining the existing static-frontend policy.

## Deployment note

Cloudflare Rocket Loader must be disabled for the Vessel HQ hostname. It
rewrites Next.js script execution and is incompatible with the per-request CSP
nonce and hydration ordering used by this release.

## Images

The release publishes the same multi-architecture OCI image under:

- `themodcrafttmc/portainer:1.2.1`
- `themodcrafttmc/portainer:latest`

Both references support Linux AMD64 and ARM64 and must resolve to the same OCI
index digest.
