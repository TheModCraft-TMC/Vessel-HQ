# Vessel HQ 1.3.5-beta.1

This beta includes the merged mobile console, live event, native extension
safety, Compose portability and Docker terminal improvements. The upstream
API and datastore compatibility baseline is Portainer 2.45.0.

- Docker Compose editors can preview a literal `docker run` command and insert
  its YAML into an empty document. Project exports preserve multi-file ordering,
  and an outdated project revision is rejected before a save can overwrite an
  external edit.
- Azure Container Instances uses the Azure bearer for creation preflight,
  refreshes cached tokens before expiry, and preserves upstream lifecycle
  responses. The provider changes passed local tests.
- The optional Docker HA example binds a directory inside the mounted shared
  filesystem so an absent mount with no local data directory fails startup.
- The extension host keeps restart limits per declared stack slot and
  preserves extension-wide safety stops.

The GitHub application archives cover Linux amd64 and arm64. `IMAGE.txt`
records the image index digest. Use the digest when testing a deployment.
Production extension activation, live Azure and cross-host HA acceptance are
tracked in [#299](https://github.com/TheModCraft-TMC/Vessel-HQ/issues/299).
