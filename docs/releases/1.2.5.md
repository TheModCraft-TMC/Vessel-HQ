# Vessel HQ 1.2.5

Vessel HQ 1.2.5 completes stale-session recovery and fixes environment image
URLs in the migrated frontend.

## Fixed

- Invalid or revoked browser authentication cookies are expired by the first
  unauthorized API response, preventing repeated `Invalid JWT token` requests.
- Header-based API authentication remains isolated and does not clear browser
  cookies when an API key or bearer token is invalid.
- Docker, Podman, Azure, Kubernetes, and Edge environment images support the
  static asset object emitted by the Next.js production build instead of
  rendering `src="[object Object]"`.

- `themodcrafttmc/portainer:1.2.5`
- `themodcrafttmc/portainer:latest`
