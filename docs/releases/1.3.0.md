# Vessel HQ 1.3.0

Vessel HQ 1.3.0 advances the component-scoped frontend foundation, refreshes
the environment experience, and makes the complete local development stack
available through one command. API and database compatibility remain at
Portainer `2.45.0`.

## Highlights

- Reorganizes the environment UI and shared SortableList primitives into
  component directories with colocated CSS Modules, tests, and stories.
- Establishes reusable Vessel depth tokens and applies the new visual language
  selectively to grouped controls, table-header control trays, list surfaces,
  and environment icon tiles while keeping data and search surfaces flat.
- Restores the administrator-only **Add environment** action to the environment
  list and preserves the existing environment-wizard route and referrer.
- Keeps GitOps workflow and source cards on the reorganized SortableList API.

## Development experience

- `npm run dev` now starts the required local backend and Next.js frontend
  together, while `npm run dev:frontend` remains available for frontend-only
  work.
- Development auto-login can initialize the local administrator and provision
  the Docker socket environment when they do not exist.
- Development-only Content Security Policy support allows Next.js hot reload
  without weakening the production policy.
- Local container startup is repeatable when the development container does
  not already exist.

## Compatibility

- The Vessel HQ product and image version is `1.3.0`.
- The upstream API and datastore schema version remains `2.45.0`.
- Development login automation is restricted to development mode and is not
  enabled in production builds.

## Container image

- `themodcrafttmc/portainer:1.3.0`
- `themodcrafttmc/portainer:latest`
