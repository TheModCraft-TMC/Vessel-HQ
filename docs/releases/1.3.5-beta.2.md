# Vessel HQ 1.3.5-beta.2

This beta fixes a login-page reload loop. A logout link or a non-OAuth login
error is now consumed once, without reloading the document. The login page
keeps the return destination and displays the logout reason. OAuth login
generates fresh state after an explicit logout.

This release includes the changes in [1.3.5-beta.1](1.3.5-beta.1.md) and keeps
the Portainer 2.45.0 API and datastore compatibility baseline. Verify the
reported reload in the affected browser workflow before promoting to stable.
Production extension activation and cross-host HA acceptance are tracked in
[#299](https://github.com/TheModCraft-TMC/Vessel-HQ/issues/299).
