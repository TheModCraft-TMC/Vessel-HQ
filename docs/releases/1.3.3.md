# Vessel HQ 1.3.3

Official dependency-security and Compose-portability release.
API/datastore compatibility remains Portainer **2.45.0**.

- Consume the published maintained Moby SDK, CLI, Compose, image and Distribution
  variants, removing the Docker monolith and Distribution v2 from the module graph.
- Preserve legacy engine version diagnostics in the maintained SDK result API.
- Update Next.js to 16.4.6.
- Add portable multi-file Compose export, reviewed ZIP import and filesystem
  revision conflict protection, preserving override order and external edits.
- Retain the preceding preview's extension settings, authorized engine events,
  signed webhook gateway, activity improvements and optional active/standby work.

## Verification and limits

The prepared application passed all frontend guards, typecheck, 378 test files /
2,541 tests, lint (zero errors, 192 warnings) and production build. Full backend
suite: 157 passing test packages. Affected and Swarm race suites passed. Module
verification passed; the November 20 full-source darwin/arm64 Go advisory report
contains zero finding records, and the fresh npm scan reported zero advisories.
These local results are separate from release-workflow results and provider
runtime acceptance of the final artifacts.

Avira on the maintainer's Mac quarantined the locally linked Linux binary as
`PUA/LINUX.Chisel.G`. Chisel is the existing Edge reverse-tunnel dependency; no
security protection was disabled or changed. This detection is disclosed rather
than treated as a successful local artifact build. The release workflow must
independently build and execute-check linux/amd64 and linux/arm64 before publishing.

Live provider acceptance of the migrated dependency graph remains incomplete.
Optional HA remains experimental and disabled by default; cross-host fencing and
failover acceptance remain outstanding. This release does not close #241, #262,
#264, #299, #300 or the synchronized Sonar backlog.

Publish the immutable `1.3.3` image for `linux/amd64` and `linux/arm64`, then
promote `latest` only to that verified digest. Mirror the same index to Docker
Hub and GHCR. Existing beta and stable version tags remain intact.
No production deployment is included in this release request.
